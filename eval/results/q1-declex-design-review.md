## F-1 (MOST IMPORTANT) — Harm gate a priori vacuous for the primary arm: D fires 0/150
S-approx, 1/100 S-prose. HARM-CLEAN certain before measurement; CLOSED-BUT-HARMFUL
unreachable. Root cause constructional: splitIdentifierTerms lowercases (fts.ts:170-184),
the generator lowercases rare words (scale-build-queries.mjs:181) and S-prose words
(:252-254), so off-stratum queries are all-lowercase by derivation and the shape gate
silences D (S-approx: 2/150 symbol-shaped tokens, digit-bearing, matching nothing; 0/150
candidates — L+D bit-identical to L; BCa degenerate [0,0]). The realistic harm surface for
a SHIPPED D — mixed-case prose queries mentioning non-target identifiers, which the
147-query log shows real agents write — is outside every stratum. Direction: vacuous-pass →
inflated "harm-free" credential inherited by F18. Fix: per-stratum fire-rate aggregates in
the RESULT; split vocabulary HARM-CLEAN (tested, non-trivial fire-rate) vs HARM-NULL
(unexposed); esc-arm harm contrast reported descriptively (only arm with exposure); scope
"harm-free" language to identifier-free queries.

S-ident scale gap," never "reproduces the vector advantage" unqualified.

## F-7 — Decision-table walk: (i) a-fortiori + harm-fail falls to AMBIGUOUS with no exit
(escalation covers only CI-width AMBIGUOUS); should be CLOSED-BUT-HARMFUL (a-fortiori is
stronger closure). (ii) Reverse-significant efficacy + Delta'-survives lands INERT-LEVER,
mislabeling an on-stratum-harmful lever. (iii) degenerate + harm-fail → CLOSED-BUT-HARMFUL:
fine. (iv) efficacy-fail + closure-met + harm-fail: 2x2-gate-first precedence should be
stated. (v) Harm CI "pooled across tiers, all-n BCa" leaves the resampling unit
unspecified — resampling query×tier rows treats 4 correlated observations as independent,
overstating precision up to 4x. Fix: map (i) to CLOSED-BUT-HARMFUL; state precedence;
rename (ii) "HARMFUL-LEVER (on-stratum)"; bootstrap unit = per-query (resample queries,
carry their tier rows together).
