# ADR 004 — Ship ranker D; identifier fusion stays out

- **Status:** Accepted and shipped (Stage 6). **IDFUSE and DECLEX are closed** — `FINDINGS.md` §4.
- **Decided:** 2026-08-06 (per ADR 003 conditions 1–3) · levers measured 2026-08-03
- **Recorded:** 2026-08-19, backfilled from `IMPLEMENTATION_PLAN.md`
- **Evidence:** [`PLAN-EXCERPT.md`](proposals/ranker-d/PLAN-EXCERPT.md) · [`EVAL.md`](proposals/ranker-d/EVAL.md) · `eval/results/q1-idfuse-design-review.md`, `q1-declex-design-review.md`

## Context

ADR 002 left exactly one real caveat against pure lexical retrieval: **the identifier stratum
degrades with corpus scale.** That caveat was the last thing standing between MAST and deleting
the vector store, so it got two pre-registered levers, run three days apart against the same
question.

## Options considered

**Q1/IDFUSE — the `identifier_fts` fusion lever.** Fuse a second, identifier-only FTS column
into the ranking. Verdict: **INERT-LEVER.** It fails as a scale rescue *and* harms off-stratum
queries. A lever that does not move the thing it targets while damaging things it does not is
the cleanest possible reject.

**Q1/DECLEX — the declaration-exact ranker.** When a query token exactly matches a declared
symbol name, anchor that declaration. Verdict: **GAP CLOSED.** It holds the identifier stratum
flat at full scale; the S-ident scale caveat is **DISCHARGED**. Efficacy **+14.67 pp
[+9.33, +20.0]**, seed-invariant decision-contrast upper bound of **exactly 0**.

The **escape variant** of D was also measured, and was **harmful as constructed**. It does not ship.

## Decision

**Ship ranker D into the existing fusion, exactly as measured, behind a default-on kill-switch.
Do not ship identifier fusion. Do not ship the escape variant.**

Staged deliberately so that no two variables moved at once:

| stage | what it did |
|---|---|
| 6.1 | port ranker D + promote Gate B's fixtures to a permanent regression suite |
| 6.2 | fusion + kill-switch (config flag, default on) |
| 6.3 | D-fire telemetry to the existing `metrics` table |
| 6.4 | verify + document |

Ranker D is **symbol-gated, full-name plus dotted-segment, case-insensitive**, without escape.

D shipped into the **existing** fusion — the measured H + D arm — *before* the vector store was
deleted. So the deletion (ADR 003) turned H + D into L + D with **no further ranking change**.
That ordering is the whole reason the shipped ranking is the ranking that was measured.

### D-fire telemetry is constitutive

Per-query: whether D fired, and the pre-fusion vs post-fusion rank of the anchored result and
of any displaced result. Without it, both the kill-switch and ADR 003's re-entry criterion 3
are decorative — there is no input signal to act on.

## Consequences

- Shipped retrieval is **lexical BM25 + ranker D under RRF**, with no vector path.
- Gate B's fixtures — dotted `Class.method` segment match, camelCase full match,
  case-insensitivity, high-multiplicity-segment ordering — are permanent tests. They were
  instrument checks; promoting them was condition 2, because an instrument check that verified
  a shipped behaviour and then got deleted is how a measured guarantee silently stops holding.
- Re-proposing identifier fusion or the escape variant requires a **fresh pre-registration**
  and a statement of what changed.

## What this does not claim

**Harm is untested.** DECLEX's verdict is "GAP CLOSED (harm untested)" — it closed the stratum
it targeted, and the question of what it costs on identifier-free or mixed-case-prose queries
(ADR 003's Gap 2) was never measured. The kill-switch exists precisely because that surface is
untested; it is an operational escape hatch for a known gap, not a general safety feature.

The efficacy figure is measured on the DECLEX arms' corpus and strata. Generalisation beyond
them is **inferred**, not measured — ADR 003's Gap 4.
